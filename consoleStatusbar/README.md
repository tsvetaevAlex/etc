## consoleStatusbar <br>
релизация динамического интерактивного status Bar  в консоли

**controls:** <br>
**F1–F4 — смена цветов**
 * F1  Red => DarkRed<br>
 * F2  Yellow => DarkYellow<br>
 * F3  Cyan => DarkCyan<br>
 * F4  Green => DarkGreen<br><br>
 * F5 — скрыть/показать курсор<br>
 * F6 — пауза/продолжить мигание<br>
 * F12 — остановка<br>
