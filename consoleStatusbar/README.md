## consoleStatusbar <br>
релизация динамического интерактивного tatus Bar  в консоли

controls:
F1–F4 — смена цветов
F1  Red => DarkRed
F2  Yellow => DarkYellow
F3  Cyan => DarkCyan
F4  Green => DarkGreen
F5 — скрыть/показать курсор

F6 — пауза/продолжить мигание

F12 — остановка

Heartbeat-счётчик
